# Bundled SVG examples

These files provide visual and structural reference patterns:

- `good/Human-Body-Synoptic.svg`: organic anatomical regions and semantic ids.
- `good/Hospital.svg`: structured hospital/bed composition.
- `aspirational/sphere-level-1.svg`: curved venue sectors.
- `aspirational/sphere-level-2.svg`: high-density individual seating.

Some source examples may predate the current decoration attribute. Do not copy
their technical metadata blindly. Every newly created or adapted map must mark
all non-data elements with:

```xml
data-okviz-area-type="decoration"
```
